# Vidéos de guide enseignant

Placez ici le fichier de démonstration :

- `create-offer.mp4` — comment créer une offre (module d’auto-formation + page Mes Offres)

Formats recommandés : MP4 (H.264), 720p ou 1080p, audio stéréo.

Vous pouvez aussi remplacer l’URL par un lien YouTube/Vimeo dans la configuration
ou dans `TutorOnboardingService.CreateOfferGuideVideoUrl`.
